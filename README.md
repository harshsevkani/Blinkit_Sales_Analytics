# Blinkit Sales Analytics SQL Project

## Overview

This project contains 90+ SQL queries performed on a Blinkit-inspired e-commerce dataset to analyze sales performance, customer behavior, product demand, revenue trends, payment methods, and operational efficiency.

The goal of this project is to solve real-world business problems using SQL and generate actionable insights that support data-driven decision-making.

---

## Datasets Used

### Customers Dataset

The dataset includes:

* Customer Information
* Customer Segments
* Registration Details
* Total Orders
* Average Order Value
* Location Data

### Orders Dataset

The dataset includes:

* Order ID
* Customer ID
* Order Date
* Payment Method
* Order Total
* Delivery Information

### Order Items Dataset

The dataset includes:

* Order ID
* Product ID
* Quantity Purchased
* Unit Price

### Products Dataset

The dataset includes:

* Product Name
* Category
* Brand
* MRP
* Margin Percentage
* Shelf Life

## Business Problems Solved

This project answers important business questions such as:

### Sales Analysis

* What is the total revenue generated?
* How many orders were placed?
* What is the average order value?
* What are the monthly revenue trends?
* Which payment methods generate the most revenue?

* Which customer segments contribute the highest sales?
* What is the purchasing behavior of customers?
